# OS-Dependent Automation Scripts

This directory contains automation scripts tailored for specific operating systems.

## Environment

- Subdirectory `environment`

Core scripts used to build a cross-platform execution environment.  
Scripts written in Python.

## Unix-like Systems

- Subdirectory `Unix_like`

Automation scripts for Unix-like operating systems, including most Linux distributions and macOS.  
Scripts written in POSIX-compliant shell.

## Windows

- Subdirectory `Windows`

Automation scripts for the Windows operating system.  
Scripts written in Batch, with calls to PowerShell where required.
