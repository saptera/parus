## Windows Automation Scripts

- `install_parus.bat`: Build `parus` project execution environment, and creates desktop shortcuts

&emsp;&emsp;&emsp;&emsp;-> Usage: *Open the file and follow the provided prompts to proceed with execution*

- `ParusTrn.bat`: Call `parus` Model Training GUI

&emsp;&emsp;&emsp;&emsp;-> Usage: *Open the file to run the program*

- `ParusDat.bat`: Call `parus` Data Processing GUI

&emsp;&emsp;&emsp;&emsp;-> Usage: *Open the file to run the program*

- `ParusRT.bat`: Call `parus` Real-time System GUI

&emsp;&emsp;&emsp;&emsp;-> Usage: *Open the file to run the program*
