## POSIX Automation Scripts

For all POSIX systems including Unix, Linux, and macOS.  
*Due to the variations in distributions, not all systems have been fully tested.*

- `install_parus.sh`: Build `parus` project execution environment, and creates desktop shortcuts

&emsp;&emsp;&emsp;&emsp;-> Usage:  
&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;*1. make it executable: run in terminal* `chmod +x install_parus.sh`  
&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;*2. launch script: run in terminal* `bash install_parus.sh`  

- `parus_trn.sh`: Call `parus` Model Training GUI

&emsp;&emsp;&emsp;&emsp;-> Usage: *run in terminal* `bash parus_trn.sh`

- `parus_dat.sh`: Call `parus` Data Processing GUI

&emsp;&emsp;&emsp;&emsp;-> Usage: *run in terminal* `bash parus_dat.sh`

- `parus_rt.sh`: Call `parus` Real-time System GUI

&emsp;&emsp;&emsp;&emsp;-> Usage: *run in terminal* `bash parus_rt.sh`
