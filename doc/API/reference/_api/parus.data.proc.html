parus.data.proc.norm_lst_gen(peak, side, level=2)[source]¶

Generate a list obeying normal distribution.

Parameters:

  • peak (float) – Peak (centre) value of output

  • side (int) – Number of samples around the peak

  • level (int) – {1 | 2 | 3}: Level of three-sigma rule within the [size]. (default: 2) - 1: [size] = 1-sigma, output list covering P(-[size], size) = 68.27% - 2: [size] = 2-sigma, output list covering P(-[size], size) = 95.45% - 3: [size] = 3-sigma, output list covering P(-[size], size) = 99.73%

Returns:

Output list of generated value

Return type:

list[float]
